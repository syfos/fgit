Each buffer can be splitted into multiple splits. Each buffer contains a Uid.

Float is a rect drawn above a buffer.

Keys:

<C-w> for creation of split window.
Two sequences --> h(horizontal), v(vertical)

After motion (<C-w>h) --> cursor in the split. User explicitly picks up a BufferKey (h: HelpPage) --> page is loaded.

<Space-c>{BufferKey} --> user can change current buffer to the desired buffer key.

e.g --> <Space-c>sa --> change to stage area.

<M-Up/Down/Left/Right> --> move cursor to the next available split in given direction.

<M-q> --> quit current buffer.
<C-q> --> quit the app.
